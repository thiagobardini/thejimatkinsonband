# Band Homepage Implementation Plan

> For agentic workers: implement inline using the executing-plans workflow. Track completion here.

**Goal:** Build a polished, responsive band homepage focused on the photograph, booking, and social links.

**Architecture:** Next.js App Router Server Components with isolated interactive client leaf components. A single source of truth provides the band's verified contact and social destinations. All media and fonts ship with the site.

**Tech Stack:** Next.js, React, TypeScript, Tailwind v4, Framer Motion, Phosphor, Outfit, Oswald.

**Spec:** `docs/superpowers/specs/2026-10-24-homepage-design.md`.

## Global Constraints

- One homepage; English copy based on the supplied biography.
- Supplied photograph, local assets, verified social URLs only.
- Midnight navy, ivory, and one muted brass accent, with visible button borders and soft corners.
- Responsive single column below 768px; accessible focus and reduced motion.
- No fabricated events or contact details, and no nonfunctional contact form.

## Review Focus

- Narrow mobile widths: no overflow, clipped words, or obscured links.
- Keyboard use: visible focus, reachable navigation, Escape closes mobile menu.
- Reduced motion: disable automatic animation and magnetic movement.
- Image failure: preserve layout and a usable, labeled fallback.
- External links: exact supplied URLs and safe new-tab behavior.
